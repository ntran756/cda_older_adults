# Reproducible code for: Socioeconomic position, socioenvironmental conditions, and subjective cognitive decline among midlife and older LGBTQIA+ adults in California 

This repository contains all code used to analyze how socioeconomic position and socioenvironmental conditions are related to subjective cognitive decline among midlife and older LGBTQIA adults in California.

Data for this code is not publicly available due to the sensitive nature of the data. Requests for data access should be made to the California Department of Aging. 

The code is written in R version 4.5.1. We used `renv` to faciliate reproducibility. Primary packages required for analysis are:
-   `tidyverse` (version 2.0.0)
-   `here` (version 1.0.1)
-   `janitor` (version 2.2.1)
-   `tableone` (version 0.13.2)
-   `mice` (version 3.18.0)
-   `miceadds` (version 3.17.44)
-   `marginaleffects` (version 0.27.0)
-   `dominanceanalysis` (version 2.1.0)
-   `future` (version 1.58.0)
-   `modelsummary` (version 2.5.0)

Status: The manuscript is currently under preparation and will be submitted to *The Journals of Gerontology, Series B: Psychological Sciences and Social Sciences*.
